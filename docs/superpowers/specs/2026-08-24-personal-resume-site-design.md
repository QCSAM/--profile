# 崔琪个人简历网站设计说明

## 目标

从零搭建一个可运行、可浏览的单页个人简历网站，准确呈现崔琪作为帝国理工学院地球科学与工程学院学生的学术背景、项目经历和复合能力。第一版用于确认整体内容结构与视觉方向，后续可根据用户提供的截图、参考网站和真实项目素材继续优化。

## 内容原则

- 所有履历信息以用户提供的《崔琪简历_photo.pdf》为准，不新增未经确认的成绩、职责或成果。
- 公开联系方式包含邮箱 `cq030317@gmail.com` 和手机号 `185-1913-1780`。
- 首版项目图片属于主题化视觉素材，不暗示为项目现场实拍；后续可替换为用户提供的真实图片。
- 中文为主要叙事语言，英文用于姓名、章节标签和少量视觉性标题。

## 视觉方向

采用“地质档案式编辑设计”，而非企业模板或常见作品集模板。

- 色彩：美拉德色系，以纸张米色、焦糖、赭石、可可棕和深咖为主。
- 排版：大号衬线标题与清晰的无衬线正文混排，结合页码、细分隔线、章节编号和较宽留白，形成书页与研究档案感。
- 图像：Hero 使用抽象岩层、地质纹理或航拍地貌视频，并覆盖深咖色渐变遮罩；项目区域使用大幅地质、生态和低碳主题图像。
- 气质：高级、克制、安静、清晰，避免玻璃拟态、霓虹渐变、过度圆角、常规模板式三栏布局和无意义装饰。
- 动效：以缓慢缩放、轻微视差、文本淡入和卡片悬停为主；尊重系统的减少动态效果设置。

## 技术设计

- 使用 React + Vite 构建单页网站。
- 主要内容以结构化数据维护，项目和能力卡片可直接替换内容与图片。
- 页面采用语义化 HTML、CSS 自定义属性和少量 React 状态。
- 导航使用页面锚点和平滑滚动，不引入路由或后端。
- 桌面端内容最大宽度约 1700px，在常见笔记本和大屏上保持合理边距；同时提供基础平板与手机适配。
- 图片设置明确尺寸或宽高比以避免布局跳动，视频使用静音、循环、自动播放和内联播放属性。
- 不在首版加入 CMS、表单后台、访客统计或账号系统。

## 错误与降级处理

- 视频加载失败时保留静态背景和所有文字内容。
- 外部主题图片不可用时显示同色系占位背景，不影响卡片阅读。
- 不支持平滑滚动或用户启用减少动态效果时，页面保持完整可用。

## 验收标准

- 本地可正常启动并访问，无阻塞性运行错误。
- 生产构建成功。
- 页面包含 Hero、Profile、Selected Work、Strengths 和 Contact 五个完整区块，Selected Work 中完整呈现三项研究/咨询项目以及网聚资本、内蒙古矿业两段经历。
- Hero 包含视频背景、标题、导航和联系按钮。
- 公开显示用户确认的邮箱与手机号。
- 桌面端最大版心约 1700px，首尾两屏具有明确的全屏体验。
- 文案中的学校、时间、角色、数字和成果均可追溯至所提供简历。
- 页面在视频或图片加载失败时仍可阅读和导航。
- 支持键盘操作，文字与背景保持足够对比度，并兼容减少动态效果设置。
